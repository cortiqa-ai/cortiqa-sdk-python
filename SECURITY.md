# Security Policy

Cortiqa takes the security of our software products and services seriously.

---

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within the Cortiqa Python SDK or backend services:

1. **Do not open a public GitHub issue.**
2. Send an email with details, reproduction steps, and potential impact to **security@cortiqa.co** or **team@cortiqa.co**.
3. We will acknowledge receipt of your vulnerability report within 48 hours and work with you to remediate the issue promptly.

Thank you for helping keep Cortiqa and our developer community safe!
